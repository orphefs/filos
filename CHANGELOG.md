# Changelog

## 0.1.0 (pre-release)

First preview.

- **Review a pull request.** Point Filos at a GitHub pull request by URL, `owner/repo#n` or number. Filos clones it into its own storage, and a step-by-step progress view runs while the agent works.
- **Graph of the change.** Modules and functions, with risk tinting computed from countable signals and external consumers called out.
- **Code beside the graph.** Click a node to see only the relevant code; unrelated regions fold to one-line gists.
- **Questions.** Predict and check questions, graded with Socratic hints. The agent proposes a review depth, and you can choose another.
- **Comments.** Your answers draft comments. Accept, reject, amend or discuss each one with the agent, then post to GitHub after a confirmation.
- **Didactic mode.** The change as a map in fog. You enter a module by answering first, and progress is coverage. Confidence per module is kept private and local.
- **Agent CLIs.** Claude Code or Codex, locked down to reading the code under review.
- **Bundled sample.** A sample review that needs no agent and costs nothing.
